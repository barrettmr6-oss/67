# Vertical Slice Milestone Tracking

Use this document to track readiness for the vertical slice gate.

## Goal
Deliver a polished, representative gameplay segment proving core loop feasibility, art direction, and technical viability on target mobile devices.

## Exit Criteria
- [ ] Core gameplay loop complete and playtestable end-to-end.
- [ ] One production-quality level/encounter demonstrating target quality bar.
- [ ] Primary player progression and fail/retry loop implemented.
- [ ] Mobile input UX validated with external playtesters.
- [ ] Performance meets target frame budget on baseline Android and iOS devices.
- [ ] Crash-free session target met during structured QA pass.

## Workstream Checkpoints

### Design
- [ ] Core mechanics signed off.
- [ ] Tutorial/onboarding flow in place.
- [ ] Session length and pacing validated.

### Engineering
- [ ] Build stability and CI checks green.
- [ ] Save/load and critical game state persistence validated.
- [ ] Telemetry/event hooks for slice KPIs integrated.

### Art and Audio
- [ ] Visual style guide applied to slice content.
- [ ] Placeholder assets removed from player-critical paths.
- [ ] Core soundscape and feedback cues implemented.

### QA and Production
- [ ] Test plan executed for gameplay, device compatibility, and regressions.
- [ ] Known-issues list triaged with severity and owner.
- [ ] Vertical slice sign-off meeting completed.
