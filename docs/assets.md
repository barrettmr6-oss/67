# Asset Naming and Budget Conventions

This document defines reproducible naming for production-ready assets and the placeholder set generated by the editor tools.

## 1. Core Naming Convention

Use `Category_Subcategory_Name_Variant` with the following required suffixes.

### Mesh and prefab names

- Character root prefab: `CHR_<Name>` (example: `CHR_Player`)
- Ball prefab: `PRP_Ball`
- Field modules: `ENV_Field_<ModuleName>`
- Stadium modules: `ENV_Stadium_<ModuleName>`
- Mesh LOD suffixes:
  - `*_LOD0` = highest quality
  - `*_LOD1` = medium quality
  - `*_LOD2` = low quality

### Texture names

- Albedo/BaseColor: `*_Albedo`
- Normal: `*_Normal`
- ORM packed map (Occlusion-Roughness-Metallic): `*_ORM`
- Emissive: `*_Emissive`
- Opacity/Mask: `*_Mask`

Example:

- `CHR_Player_Body_Albedo`
- `CHR_Player_Body_Normal`
- `ENV_Stadium_Concrete_ORM`

### Animation clip names

- Idle: `ANM_<Character>_Idle`
- Locomotion: `ANM_<Character>_Run`, `ANM_<Character>_Sprint`
- Actions: `ANM_<Character>_Kick`, `ANM_<Character>_Slide`
- Additive overlays: `ANM_<Character>_<Action>_Add`

## 2. Placeholder Asset Set

The placeholder generator produces:

- `Assets/Placeholders/Characters/CHR_Player.prefab`
  - rig root + minimal humanoid-like bone hierarchy
  - skinned mesh renderer on `CHR_Player_LOD0` and reduced fallback renderer on `CHR_Player_LOD1`
  - capsule collider
- `Assets/Placeholders/Props/PRP_Ball.prefab`
  - sphere mesh with sphere collider
  - two LOD renderers (`PRP_Ball_LOD0`, `PRP_Ball_LOD1`)
- `Assets/Placeholders/Environment/ENV_Field_Main.prefab`
  - field plane + boundary strips
  - box colliders + LOD group
- `Assets/Placeholders/Environment/ENV_Stadium_Section_A.prefab`
  - modular section chunk for stadium layout tests
  - compound primitive colliders + LOD group

## 3. Mobile-First Material Presets (PBR)

Create and reuse these presets:

- `MAT_Mobile_Player`
- `MAT_Mobile_Ball`
- `MAT_Mobile_Field`
- `MAT_Mobile_Stadium`

Preset guidelines:

- Metallic workflow with conservative smoothness (`0.2-0.5`)
- Disable expensive features unless required (clear coat, parallax, detail maps)
- Use a single normal map only where silhouette/detail improvement is visible in gameplay camera
- Keep shader variants minimal (shared shader, minimal keyword divergence)

## 4. Texture Budget Limits

Mobile-first texture caps enforced by validation:

- Characters:
  - Albedo/Normal/ORM max: `1024 x 1024`
- Ball and small props:
  - Albedo/Normal/ORM max: `512 x 512`
- Field and stadium modules:
  - Tile textures max: `1024 x 1024`
  - Unique hero module textures max: `2048 x 2048` (exception; justify per asset)
- UI-independent decals/masks:
  - Max: `512 x 512`

General compression targets:

- Color textures: ASTC 6x6 (or ETC2 fallback)
- Normal maps: ASTC 6x6/8x8
- ORM masks: ASTC 8x8 where acceptable

## 5. Collision Naming

Collision child nodes should use prefix `COL_`.

- `COL_PlayerCapsule`
- `COL_BallSphere`
- `COL_FieldBoundary`
- `COL_StadiumBlocker`

These names allow automated collider and gameplay layer validation.
